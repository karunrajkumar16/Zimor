# Zimor Brand Typography Fonts

According to the official Brand Guidelines (Page 12), the Primary Typeface is **Akzidenz Grotesk**.
Because Akzidenz Grotesk is a commercial typeface, official licensed font files must be placed here.

### Required Font Files (WOFF2):
1. `AkzidenzGrotesk-Regular.woff2` (Weight: 400, Style: normal)
2. `AkzidenzGrotesk-Medium.woff2` (Weight: 500, Style: normal)
3. `AkzidenzGrotesk-Semibold.woff2` (Weight: 600, Style: normal)

Once placed in this directory, the website will automatically serve them via `@font-face` and `next/font/local`.
Until these files are supplied, a clean neo-grotesque system fallback stack is used.
